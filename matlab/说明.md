# MATLAB 版 HER/HOR 计算程序

把 `batch_calculator/` 里的 Python 程序（`calculator.py` / `eta_sweep.py` /
`near_equilibrium_sweep.py`）翻译成 MATLAB，用于 `Linear Equation` 的
电化学动力学计算。

**Python 原程序完全没有改动**，两套代码可以并存、互相验证。

---

## 零、怎么运行（最省事的办法）

**双击打开 `RUN_ME.m`，按 F5。**

就这两步。这个脚本会自动把本目录加进搜索路径，然后用一个数字选择要跑哪个任务：

```matlab
TASK = 1;     % ← 只改这个数字
```

| TASK | 做什么 | 点数 | 耗时 |
|---|---|---|---|
| **1** | 快速出图，η ∈ [-0.25, 0.25] V，步长 0.005 | 101 | ~1 分钟 |
| **2** | 精细出图，步长 0.001（论文用图建议选这个） | 501 | ~5 分钟 |
| **3** | 最精细出图，步长 0.0005 | 1001 | ~9 分钟 |
| **4** | 换氢气压 p = 0.1 出图 | 501 | ~5 分钟 |
| 5 | 基线过电位扫描（等价 `eta_sweep.py`） | 112 | ~1 分钟 |
| 6 | 近平衡区扫描（等价 `near_equilibrium_sweep.py`） | 251 | ~2 分钟 |
| 7 | 批量计算 Python 那个模板 CSV，不出图 | 1 | 秒级 |
| 8 | 批量计算你自己的 CSV（需先放到 `my_input.csv`） | — | — |

跑完的结果都写在**本目录**下，文件名见下面第二节。

> 注意：`RUN_ME.m` 用的是英文文件名，是为了保证在命令行/批处理下也不会因为编码出问题；
> 文件里面的注释和提示信息都是中文。原来中文名的版本已改名为 `RUN_ME.m`。

## 三、翻译要点（重要）

### 1. 高精度线性方程组：`vpa` 对应 `Decimal`

`solve_coverages` 默认用 **60 位有效数字**求解，对应 Python 的
`Decimal` + `localcontext(prec=60)`。

**为什么必须高精度**：这个 10×10 矩阵的元素从 `1e-13` 跨到 `1e12`，
条件数约 **3.5e22**。双精度下矩阵完全奇异（实测 `RCOND = 3.462e-23`），
解出的覆盖率会出现负值。所以：

```matlab
solve_coverages(params)              % 默认 'vpa'，60 位，稳妥
solve_coverages(params, 'double')    % 快，但本例会因负覆盖率报错
```

需要 Symbolic Math Toolbox（本机已授权）。

### 2. 数值积分：用 `quadgk` 而不是 `integral`

scipy 的 `integrate.quad` 是 QUADPACK 的自适应 Gauss–Kronrod 求积，
MATLAB 里同源的函数是 **`quadgk`**（`integral` 不支持 `MaxIntervalCount`）。
参数一一对应：

| Python | MATLAB |
|---|---|
| `epsabs=1e-12` | `'AbsTol', 1e-12` |
| `epsrel=1e-12` | `'RelTol', 1e-12` |
| `limit=1000` | `'MaxIntervalCount', 1000` |

### 3. 字段名映射：`A-1` → `Am1`

MATLAB 结构体字段名不能含 `-`，所以逆反应统一用 `m` 表示减号。
写出 CSV 时由 `field_to_header` 还原成 `A-1`，**列名与 Python 版逐字符一致**。

### 4. 参数顺序有个坑

喂给 `solve_coverages` 的 34 个速率，必须是**每个族的正、逆相邻**：

```
A1..A4, A-1..A-4, D1..D4, D-1..D-4, V1..V4, V-1..V-4, H1..H4, H-1..H-4, T_rate, T_reverse_rate
```

**不是**"先所有正反应、再所有逆反应"。写错会让矩阵的列整块错位，
覆盖率完全错误（这个坑已经踩过一次，`rate_field_order.m` 里留了注释）。

### 5. 输出列顺序

与 Python 版 pandas 的 dict 插入顺序严格一致：

```
输入列（保持原顺序） → GD1..GD4, GT
→ A1,A-1,A2,A-2,...,D4,D-4, T_rate, T_reverse_rate
→ V1,V-1,...,H4,H-4
→ x1..x10 → rD1..rD4, rH2
```

共 80 列。浮点用 `%.17g` 写出，读回来与原 double 逐位相同。

## 四、与 Python 版的数值对比

用 `input_template.csv`（单情形）对拍，79 个数值列：

| 指标 | 结果 |
|---|---|
| 列名与顺序 | **完全一致（80 列）** |
| 行数 | 一致 |
| 54 个速率常数 / 自由能 | 相对误差 ~**1e-16**（机器精度） |
| 覆盖度 x1..x10 | 绝对偏差 ~**1e-10** |
| **中位相对误差** | **0** |
| 最大相对误差 | 2.98e-03（出现在 x1） |

**关于 x1 的 0.3%**：x1 的量级只有 `6.5e-8`，而 x5 是 `0.98`，
两者相差 1500 万倍。矩阵条件数 1e22，这个极小分量是**病态系统里最不可靠的
输出**——Python 和 MATLAB 都只能保证它的前几位。物理上有意义的量
（rH2、rD1..rD4）绝对偏差在 `1e-10` 以下。

**建议**：论文里若引用 x1，最好说明它是最小分量、相对不确定度较大；
或者直接以 rH2 为准。

## 五、注意事项

1. **运行前先 `addpath` 本目录**，否则函数找不到。
2. `rH2_eta_curve` 结果会写到本目录；若要写到别处，用
   `'outputDir', '路径'`。
3. 命令行批处理运行示例：

   ```powershell
   & 'D:\MATLAB\bin\matlab.exe' -batch "addpath('...\matlab'); rH2_eta_curve();"
   ```

4. 读结果 CSV 时必须带 `'VariableNamingRule','preserve'`，
   否则 `A-1` 这类列名会被 MATLAB 改写：

   ```matlab
   T = readtable('rH2_eta_results.csv', 'Encoding','UTF-8', ...
                 'VariableNamingRule','preserve');
   ```
